## Anchor rule

Read the canonical global rule and temporary notice before serious project work this week.

A handoff, loader, activation block, or project continuation request authorizes only context loading, source reading, verification, checkpointing, and documentary preservation.

It does not authorize new drafting, substantive rewriting, file mutation, client communication, legal filing, service start, local sync, broad scan, destructive action, or operational execution.

## Memory rule

Memory is not a source of truth.

If an important rule exists only in memory and may be lost, preserve it in chat or Git as a documentary checkpoint and verify by read-back.

## Safeguards

- Do not create new creative or substantive content without explicit user authorization.
- Do not overwrite substantive existing content without explicit user authorization.
- Use simple ASCII storage filenames and path segments.
- Verify external writes by read-back before saying written, saved, נכתב, נשמר, or סיימתי.
- If Drive creates an empty document or fails verification, stop retrying that Drive document and preserve in Git or chat first.
- If a stricter repository-specific rule exists, the stricter rule controls.

## If unsure

Stop at a checkpoint and do not execute.
